# ECHO - Sonar Escape

You are blind. Sound is your only light. But everything hears.

A stealth maze game made in Godot 4.7. Use sonar pings to reveal the maze,
but every ping tells the hunters where you are.

(ITCH LINK)

## How to play
- Move: WASD / Arrow keys
- Sonar ping: Space / Mouse click
- Collect all shards, then reach the green exit
- Avoid the hunters. They hear your pings and chase you
- Every sector adds more hunters and shards

## Features
- Random maze every level
- Hunters with pathfinding (wander, alert, chase)
- Risk vs reward: pinging helps you see but gives you away
- High score saved, sound effects generated in code (no assets)

Built with Godot 4.7. Code written with AI assistance.
